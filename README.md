## About KRNL PC

KRNL PC is a Windows-based Lua executor created for Roblox. It lets users run custom scripts within the Roblox client for purposes such as automation, debugging, and gameplay customization. The interface is intentionally direct: connect to Roblox and inject with one click without a lengthy setup process.

Version 3.3 is optimized for current Windows installations and keeps its installation footprint low. Its script hub collects more than 500 community submissions and sorts them by game and purpose. Compatibility updates are handled through the built-in updater, while multiple interface languages make the application easier to use internationally. It can be used for testing personal Lua projects or loading scripts from the included collection.

## Frequently Asked Questions

**Is KRNL PC safe to use?**  
Third-party software should always be used carefully and at the user's own risk. KRNL PC is supplied as-is; review the source code where possible and be cautious with scripts obtained from outside sources.

**Does it remain compatible when Roblox is updated?**  
The automatic update component generally delivers compatibility patches within 24-48 hours after a Roblox release. In unusual situations, a manual update can still be necessary.

**What distinguishes KRNL PC from other executors?**  
The project prioritizes a lightweight workflow without a key requirement. It also includes a script hub and a persistent queue, and does not depend on external components or paid subscriptions.

**Could script execution result in a Roblox account ban?**  
Any executor carries account-related risk. Account safety is not guaranteed, and each user is responsible for how the tool is used.

**Where does KRNL PC keep scripts and queue information?**  
Local scripts and queue records are saved under the `scripts/` directory in SQLite databases. The README states that this information is not transmitted externally.
